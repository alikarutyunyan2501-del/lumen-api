### 🛠 Стек
- **Backend:** Python 3.11, FastAPI, Uvicorn
- **DB & ORM:** SQLAlchemy 2.0, Pydantic v2, SQLite (dev) / PostgreSQL (prod), Alembic (внедрение)
- **Auth:** JWT (в процессе), OAuth2
- **Tools:** Git, Docker (в процессе), Swagger UI, Pytest (план)
